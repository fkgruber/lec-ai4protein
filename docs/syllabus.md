## Course Description

This course explores the intersection of artificial intelligence and protein science. Students will learn modern deep learning techniques and their application to protein structure prediction, protein design, and protein function analysis. The course combines theoretical foundations with hands-on implementation of state-of-the-art models.

---

## Learning Objectives

By the end of this course, students will be able to:

1. Represent proteins numerically for machine learning applications
2. Implement and train neural networks for protein-related tasks
3. Understand and apply transformer and graph neural network architectures
4. Work with protein language models (ESM) for various downstream tasks
5. Understand the architecture of AlphaFold, RFDiffusion, and ProteinMPNN
6. Implement simplified versions of major protein AI models

## Homework Assignments

1. **HW1: Protein Property Prediction** - Train a neural network to predict protein solubility
2. **HW2: Contact Map Prediction** - Implement CNN for residue contact prediction
3. **HW3: Sequence Generation** - Use ESM for masked sequence completion
4. **HW4: Protein Design** - Design sequences for given backbone structures

---

## Project

Students will complete a course project applying AI methods to a protein-related problem. Projects can be:
- Reproduction of a published method
- Novel application to a new dataset
- Extension of course mini-implementations

**Deliverables:**
- Project proposal (Week 10)
- Final report and code (Finals week)
- 10-minute presentation
